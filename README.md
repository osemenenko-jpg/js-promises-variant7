# Практична робота 10.1 — Promises

## Варіант 7: Online Store Cart

### Опис
Система обробки кошика з використанням Promise chaining:

- Валідація
- Розрахунок суми
- Знижка
- Податок
- Оформлення замовлення

### Як запустити

1. Відкрити index.html у браузері
2. Відкрити консоль (F12 → Console)

### Особливості

- Використано Promise
- Ланцюжки .then()
- Обробка помилок через .catch()
- finally блок
- 20% шанс помилки на кожному етапі
